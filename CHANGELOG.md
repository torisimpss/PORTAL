## 2026-10-10 — Back buttons and app-like navigation (change request 1)

- Added a Back button to every screen except the landing screen. It sits top-left in a fixed header (Back · Kerry Lemon · Index).
- Back retraces the visitor's own path. If they arrived directly (QR scan or shared link), it goes up a level instead: page → index → landing.
- Screens now slide in like an app: from the right going forward, from the left going back (turned off for people who prefer reduced motion).
- App feel: fixed blurred header, tap feedback on buttons and rows, no rubber-band overscroll, support for iPhone safe areas.
- Desktop: Back sits above the page content; the side index stays visible.
